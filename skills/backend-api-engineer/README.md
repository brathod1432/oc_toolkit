# Backend API Engineer

## Summary

Backend API design and implementation covering schemas, validation, auth boundaries, pagination, idempotency, errors, logging, and safe CORS.

## What This Skill Helps With

- REST API design.
- schema validation.
- authorization boundaries.
- pagination and idempotency.
- safe error handling.

## Typical Use Cases

- creating or changing HTTP APIs.
- defining request and response schemas.
- adding pagination, rate limits, or idempotency.
- reviewing auth boundaries and error handling.

## Safety Model

This skill is local-first. Network access, package installation, destructive commands, cross-workspace file access, credential handling, browser profile access, account actions, and production-impacting changes require explicit user approval.
