# Examples: Python Engineer

## Example: CLI utility

User asks:
> Write a Python CLI to rename report files.

Skill behavior:
- Design dry-run output, literal path handling, and clear errors.

Safety check:
- Ask before actual rename operations.

Expected output:
- CLI behavior and verification.

## Example: CSV parser

User asks:
> Parse messy CSV exports.

Skill behavior:
- Use standard library or existing dependencies and validate headers.

Safety check:
- Do not print sensitive rows.

Expected output:
- Parsed output and edge-case tests.

## Example: Type cleanup

User asks:
> Add typing to this module.

Skill behavior:
- Introduce useful annotations without broad rewrites.

Safety check:
- Do not change runtime behavior unexpectedly.

Expected output:
- Focused patch and tests.

## Example: Error handling

User asks:
> Make this script fail clearly.

Skill behavior:
- Replace broad exceptions with actionable errors and exit codes.

Safety check:
- Do not hide security or data loss failures.

Expected output:
- Error behavior summary.

## Example: Packaging check

User asks:
> Review this Python package layout.

Skill behavior:
- Check module boundaries and metadata awareness locally.

Safety check:
- Do not publish or install packages.

Expected output:
- Findings and recommended cleanup.
